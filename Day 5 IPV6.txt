1. subnet for 8 offices using network address fd00:1::/64
Convert - 8 = 3 bits
Add bits to existing slash/subnet = 3 + 64 = /67 (5th,1st,2i) 

2. subnet for 4 offices using network address fd00:2::/88
Convert - 4 = 2 bits			hextet | hexadecimnal | i
add bits to subnet = 2+88 = /90     	6	 3rd		4

fd00:0002:0000:0000:0000:0000:0000:0000:/90  = fd00:2::/90 
fd00:0002:0000:0000:0000:0040:0000:0000:/90  = fd00:2::40:0:0/90 
				1st usable:    fd00:2::41:0:0/90 
				Last nonAny:   fd00:2::7F:FFFF:FF7F/90 
				1st anyIP:     fd00:2::7F:FFFF:FF80/90 
				Last usable:   fd00:2::7F:FFFF:FFFF/90 
				not yours :    fd00:2::80:0:0/90 
fd00:0002:0000:0000:0000:0080:0000:0000:/90  = fd00:2::80:0:0/90 
fd00:0002:0000:0000:0000:00C0:0000:0000:/90  = fd00:2::C0:0:0/90
